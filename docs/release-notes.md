# TripToExcel — notes de version

Version anglaise : [English](en/release-notes.md).

## 1.0 — 7 octobre 2026 (code de version 2)

```
1.0 — première version.
Enregistrement automatique des trajets dès que le Bluetooth de la voiture se connecte, avec un délai de reconnexion pour ne pas couper un trajet en deux.
Démarrage et arrêt manuels pour les trajets non détectés.
Export Excel (.xlsx) pour les notes de frais, avec adresses et liens Google Maps.
Données locales : ni compte, ni serveur, ni publicité, ni analyse.
```
