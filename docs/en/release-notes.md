# TripToExcel — release notes

French version: [Français](../release-notes.md).

## 1.0 — 7 October 2026 (version code 3)

```
1.0 — first release.
Automatic trip logging when your car's Bluetooth connects, with a reconnect grace period so brief dropouts do not split a trip.
Manual start/stop for trips that detection misses.
Excel (.xlsx) export for expense reports, with addresses and Google Maps links.
Local-only data: no account, no server, no ads, no analytics.
```
